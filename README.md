# AI Gift Recommendation System

## About

AI Gift Recommendation System is a web application that uses Google Gemini AI to recommend personalized gifts.

## User Inputs

- Age
- Relationship
- Occasion
- Interests
- Budget

## Technologies

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- GitHub
- Render

## Working

The user enters their gift requirements. The application sends the information to the Gemini AI model. Gemini analyzes the information and generates five personalized gift recommendations.

## Features

- Personalized gift recommendations
- Budget-based suggestions
- Occasion-based suggestions
- Interest-based suggestions
- AI-generated explanations
